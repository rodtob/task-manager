# Task Manager App

A simple **React + Zustand** task management application with full CRUD functionality, priority flags, and persistence via localStorage. This project is optimized for both desktop and mobile devices.

---

## Features

- **Add Tasks**: Create new tasks with a title and priority (High, Medium, Low).  
- **Edit Tasks**: Modify task title and priority inline.  
- **Toggle Completion**: Mark tasks as complete or incomplete.  
- **Delete Tasks**: Delete tasks with a confirmation popup.  
- **Task Counter**: Shows total tasks and completed tasks.  
- **Filtering**: Filter tasks by status (All, Complete, Incomplete) or search by title.  
- **Priority Indicators**: Each task shows a colored badge or flag indicating its priority.  
- **Persistent Storage**: Tasks are saved in `localStorage` using Zustand persistence.  
- **Responsive Design**: Works on desktop and mobile (flexible layout).  

---

## Technologies Used

- **React** (Functional components, Hooks)  
- **Zustand** (State management with persistence)  
- **Tailwind CSS** (Styling and responsive layout)  
- **Vite** (Fast development setup)

## Getting Started

## Requirements

- Node.js v18+

1. Clone the repository:

git clone https://github.com/rodtob/task-manager.git

npm install

npm run dev
